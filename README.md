# Flight Navigator: MVP MOW–IST–HKT Backend

FastAPI бэкенд для поиска и оптимизации стыковочных авиамаршрутов по направлению **Москва (MOW: SVO/VKO/DME) — Стамбул (IST/SAW) — Пхукет (HKT)** с учётом пересадок, смены аэропорта, багажа и способов оплаты для граждан РФ.

---

## 🛫 Возможности

1. **Поиск и оптимизация стыковок (MOW → IST/SAW → HKT)**:
   - Проверка допустимого окна пересадки (`min_layover_hours`, `max_layover_hours`).
   - Контроль пересадки между аэропортами Стамбула (IST ↔ SAW, минимально рекомендованное время — от 4.5 часов).
   - Расчёт единых сквозных билетов (`single_ticket`, `through_baggage`) со скидкой и комбинированных маршрутов (interline / раздельные билеты).
   - Определение права на бесплатную экскурсию от Turkish Airlines (`Touristanbul` при стыковке от 6 до 24 часов).
   - Сортировка по цене, общему времени в пути или длительности пересадки.

2. **Справочник транзита и визовых правил**:
   - Правила въезда и безвизового нахождения в Турции (до 60 дней) и Таиланде (до 60 дней).
   - Требования к сроку действия загранпаспорта.
   - Варианты трансфера между Новым аэропортом Стамбула (IST) и Сабиха Гёкчен (SAW): экспрессы Havaist, метро M11/M4, такси.

3. **Платежная совместимость**:
   - Рекомендации по оплате билетов (UnionPay российских банков, карты зарубежных банков, оплата в рублях через российские агентства/агрегаторы).

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск сервера разработки

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Документация Swagger UI доступна по адресу: [http://localhost:8000/api/v1/docs](http://localhost:8000/api/v1/docs).

### 3. Запуск тестов

```bash
pytest -v
```

## 📡 Примеры API эндпоинтов

- `GET /api/v1/health` — проверка работоспособности сервиса.
- `GET /api/v1/airports` — список аэропортов (SVO, VKO, DME, IST, SAW, HKT).
- `GET /api/v1/guide/IST` — справочник по транзиту в Стамбуле (визовые требования, трансфер между аэропортами, карты).
- `GET /api/v1/routes/quick-search?departure_date=2026-10-01&sort_by=price` — быстрый поиск рейсов.
- `POST /api/v1/routes/search` — полный поиск с фильтрами по окну пересадки, аэропортам и количеству пассажиров.
